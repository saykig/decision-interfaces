## Result and assumptions

For a nonempty finite ordered list of senders, independent private bits with
`0 < p_i < A/(A+B) < 1`, `A,B > 0`, positive disclosure costs, and the original
hard-evidence timing, at every `0 ≤ e < B` an actual target sequential equilibrium
exists exactly when some position satisfies

```
k_j ≥ η_j ∏_{l>j} p_l.
```

The target is all silence followed by receiver cooperation on path; off-path
continuation reports are permitted. Sender and receiver ties can be selected
favorably. The formal theorem includes every history-dependent mixed continuation.
The complete feasible-fine set is `[0,∞)` if a weak blocker exists and `[B,∞)`
otherwise; its least element is attained. The core proof does not need positivity
of the reward coefficients, although the inherited strategic model assumes it.
Orders are position-indexed; permuting all primitive vectors supplies any order.
